# 万物 · 地球生命全景图鉴

纯前端网站，无需安装与构建：**直接双击 `index.html` 用浏览器打开即可**（推荐 Chrome / Edge / Safari 最新版）。
要让局域网或外网的其他设备访问，用 `python3 tools/serve.py 8080` 启动服务器。它会把 30 多个脚本合并成一个带指纹、可长期缓存的文件并做 gzip 压缩（经过外网隧道时每个请求都要来回约 2 秒，文件多了容易卡在 0%），其余文件让浏览器每次确认是否更新，改完代码对方刷新就能看到新版本。本机双击 `index.html` 时仍按单独文件加载。

外网访问用 Cloudflare 临时隧道（链接每次启动都会变）：`~/.local/bin/cloudflared tunnel --protocol http2 --url http://127.0.0.1:8080`。
用 `--protocol http2` 是因为当前网络的 QUIC（UDP）连接不稳定；用 `127.0.0.1` 而不是 `localhost`，避免隧道走 IPv6 连不上只监听 IPv4 的服务器。
如果网络慢或文件下载失败，加载页会提示原因并提供“重新加载”按钮，而不是一直停在 0%。
所有依赖（three.js、d3、topojson、世界地图数据）都已放在 `vendor/` 中，离线也能浏览大部分内容；卫星贴图、实拍照片和 iNaturalist 实时物种库需要联网。

## 真实照片

所有生物照片都是**实时引用原始来源**，项目里不存任何图片，浏览器也不会把它们写入 localStorage 等本地存储（只在当前页面的内存里缓存）：

1. **Wikipedia 页面主图**（图片托管在 Wikimedia Commons）：按学名批量查询，每次最多 50 个物种。
2. **iNaturalist**：Wikipedia 没有合适照片、或 Wikipedia 无法访问时，改用 iNaturalist 物种默认照片（按学名精确匹配，限速约每秒 1 次）。
3. **Wikimedia Commons 图库搜索**：前两者都没有时，按学名搜索 Commons 中的实拍照片。

分布图、示意图、矢量图、古生物复原画等非实拍图片会被自动跳过。点开任意生物的详情，照片左下角会显示作者、授权协议和原图链接；详情里还有 iNaturalist 实拍和 GBIF 分布记录的外链。
少数已灭绝或极少被拍到的深海物种，公开授权的图片只有标本照片或科学绘图。需要联网才能显示照片，离线时会自动显示图标。

如果某个物种匹配到的照片不理想，可以在数据里加 `wk:'维基百科条目名'` 指定对照条目，例如 `wk:'Pando (tree)'`。

| 07 万物名录 | 全部生物：实时接入 iNaturalist 全球分类库（约 113 万个已命名物种），从“生命”根节点出发，动物、植物、真菌、色藻、原生生物、细菌、古菌、病毒八大类逐级下钻到任意一个物种；每个类群显示物种总数，可“随机遇见一个物种”；搜索结果里的生物可一键“在万物名录中定位”。需要联网 |

首页是 three.js 3D 粒子标题：在“万物 / 生命 / 演化 / 灭绝 / 深海 / 共生 / 微光 / 希望”等词语与地球、DNA 双螺旋、生命树、蓝鲸、恐龙、水母、蘑菇、细菌、幼苗等形态之间以爆裂、旋涡、内爆、落雨、波浪等方式变形；还有由实拍照片组成的 3D“物种星球”和“如果地球历史只有 24 小时”生命时钟。全站有鼠标粒子尾迹、点击迸发、页面切换冲击波和 3D 滚动入场。

搜索（`⌘/Ctrl + K`）除了本站名录，还会实时查询 iNaturalist 全球物种库（50 多万个物种），任何生物都能搜到并查看实拍照片与简介。

**“全部生物”入口**：六个视角都有醒目的实时入口按钮（旋转发光描边、LIVE 脉冲点、实时数量滚动），颜色跟随当前深度带 / 地质年代 / IUCN 等级变化；深海的悬浮按钮随下潜深度切换，尺度的按钮随缩放实时计数。点开后的名单抽屉带骨架屏加载与数量滚动动画。

**扫码访问**：导航栏右上角「扫码访问」按钮会把当前网址生成二维码（本地生成，离线可用），手机扫码直接打开；可勾选是否带上当前视角、复制链接、下载二维码图片。用 localhost 打开时会提示改成局域网或外网地址。

快捷键：`⌘/Ctrl + K` 全局搜索 · `1`–`7` 切换视角 · `0` 首页 · `Esc` 关闭 · 时间线 `← →` · 尺度 `空格` 自动漫游

## 目录结构

```
index.html          页面外壳
css/style.css       全部样式
js/app.js           路由、星空背景、详情弹窗、搜索

js/share.js         扫码访问：二维码弹窗
js/live.js          各视角共用的“全部生物”实时名单抽屉（iNaturalist / OBIS / PBDB / Wikidata），学名自动配中文名
js/fx.js            全站特效：粒子尾迹、迸发、冲击波、3D 入场、文字解码
js/hero3d.js        首页 3D 粒子变形引擎
js/views/*.js       八个视图（home / map / timeline / tree / ocean / scale / redlist / all）
js/data/*.js        数据：species / species2 现生物种、species3 扩充名录（由 iNaturalist 生成的快照）、extinct 灭绝与地质年代、tree 生命树、ocean 深海、scale 尺度、redlist 红色名录、sizes Wikidata 生物尺寸快照
tools/              数据快照的生成脚本（见 tools/README.md）
vendor/             d3 7.9、topojson-client 3.1、world-atlas 110m 地图、qrcode-generator 1.4.4（MIT）
```

## 添加内容

数据都是普通的 JS 数组，照着已有条目的格式追加即可，例如在 `js/data/species.js` 里加一个物种：

```js
{n:'中文名', e:'English name', l:'Latin name', c:'mammal', r:'asia', p:[经度, 纬度], i:'🐼', s:'VU',
 z:'体型', h:'栖息地', d:'介绍', f:'冷知识'}
```

数字均为近似值，综合自 IUCN 红色名录、古生物学文献与公开科普资料，仅供科普参考。
